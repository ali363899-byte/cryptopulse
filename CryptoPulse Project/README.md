# CryptoPulse ⚡

A sleek, responsive cryptocurrency market tracker displaying real-time prices, 24-hour trends, and market ranks for top global assets.

## Features
- **Real-Time Data:** Live market updates powered by the CoinGecko Public API.
- **Instant Search:** Dynamic filtering by cryptocurrency name or symbol without page reloads.
- **Dark UI:** Glassmorphism-inspired dark dashboard built with pure CSS.
- **Zero Config:** Vanilla HTML, CSS, and JavaScript. No npm installs or API keys required.
